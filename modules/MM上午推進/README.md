# MM 上午推進模組

## 定位

本模組以正式模組結構管理「MM 上午推進」的規則來源、執行流程、任務卡規格、精簡提示詞、規則追溯與等效測試。

目前只實作「MM 上午推進」，不包含：

- MM 睡前回顧
- 對話歸檔
- 台中流程職缺精選本身
- 其他專用排程或 AI 提示詞

上述流程只會在任務分工時被引用，不納入本模組管理。

## 路徑原則

- 模組根目錄保留通用技術名稱 `modules/`。
- 模組名稱與規格文件使用繁體中文。
- 目前正式路徑為 `modules/MM上午推進/`。

## 目標

1. 將長提示詞拆成可維護的正式規格。
2. 保留原提示詞的行為、邊界與失敗處理。
3. 產出可供正式排程使用的精簡提示詞。
4. 用固定驗收案例確認精簡前後等效。
5. 保留未來擴充能力，但不預先實作其他模組。

## 模組內容

- [`工作流程.md`](工作流程.md)：完整流程、角色邊界與失敗處理
- [`任務卡規格.md`](任務卡規格.md)：今日最小行動任務卡規格
- [`執行提示詞.md`](執行提示詞.md)：正式排程候選提示詞
- [`規則對照表.md`](規則對照表.md)：原提示詞條款與新規格的追溯關係
- [`驗收測試.md`](驗收測試.md)：等效驗收案例與通過標準

## 版本狀態

- 模組版本：`0.1.0-draft`
- 目前狀態：草稿審查
- 正式排程：尚未替換

## 發布門檻

只有同時符合以下條件，精簡提示詞才可進入正式排程替換：

1. 規則對照表無缺漏。
2. 必要驗收案例全部通過。
3. 使用者完成內容確認。
4. GitHub PR 合併並完成 `main` 回讀。
5. 正式排程更新後完成一次回讀驗證。

在上述條件完成前，不得以本模組候選提示詞取代正式排程。
