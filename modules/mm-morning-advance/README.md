# MM 上午推進模組

## 定位

本模組以正式模組結構管理「MM 上午推進」的規則來源、執行流程、任務卡規格、精簡提示詞與等效測試。

目前範圍只涵蓋「MM 上午推進」，不包含：

- MM 睡前回顧
- 對話歸檔
- 台中流程職缺精選
- 其他專用排程或 AI

## 目標

1. 將長提示詞拆成可維護的規則模組。
2. 保留原提示詞的行為與失敗處理。
3. 產出可供排程使用的精簡提示詞。
4. 用固定驗收案例確認精簡前後等效。
5. 保留未來擴充至其他提示詞的結構，但不預先實作。

## 模組內容

- `workflow.md`：上午推進完整流程與角色邊界
- `task-card-schema.md`：今日最小行動任務卡規格
- `runtime-prompt.md`：排程使用的精簡提示詞候選版
- `traceability.md`：原提示詞條款與新規格對照
- `tests.md`：等效驗收案例

## 發布原則

本模組先以分支與草稿 PR 形式審查。通過前不得直接取代正式排程提示詞。
