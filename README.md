# MM Governance

MM Governance 是 MM 提供給雲端 AI 使用的公開治理規範入口。

## 閱讀順序

任何參與 MM 對話或工作的雲端 AI，開始前應依序閱讀：

1. [`README.md`](README.md)
2. [`AGENTS.md`](AGENTS.md)
3. [`生成式AI共同聊天規範.md`](生成式AI共同聊天規範.md)

若無法讀取上述文件、無法確認版本，或文件內容互相衝突，應先向使用者說明，不得自行補完規則。

## 權威與同步模型

```text
本機 MM（唯一編修來源）
→ 使用者確認可公開內容
→ GitHub 公開治理鏡像
→ 雲端 AI 對話前閱讀
```

- 本 Repository 是雲端 AI 可讀取的公開治理鏡像。
- 本機 MM 維持唯一編修來源（Single Source of Truth）。
- GitHub 內容只有在完成同步並可回讀驗證後，才視為已發布。
- 本機與 GitHub 不一致時，不得猜測哪一份較新；應停止引用衝突規則並請使用者確認。

## 公開邊界

本 Repository 只發布去個人化的共通規範，不收錄：

- 個人目前狀態、卡點、提醒與私人決策
- 聊天逐字稿與未公開專案內容
- 本機絕對路徑
- 帳號、Token、Slack 識別資訊或其他敏感資料
