# MM Governance

MM Governance 是 MM 提供給參與工作的 AI 使用的公開治理規範入口。

## 閱讀順序

任何參與 MM 對話或工作的 AI，開始前應依序閱讀：

1. [`README.md`](README.md)
2. [`AGENTS.md`](AGENTS.md)
3. [`AI共同聊天規範.md`](AI共同聊天規範.md)

若無法讀取上述文件、無法確認版本，或文件內容互相衝突，應先向使用者說明，不得自行補完規則。

## 權威與同步模型

```text
GitHub main（公開共通治理來源）
→ commit 與版本回讀驗證
→ 本機每 6 小時唯讀同步
→ 雲端與本機 AI 工作前閱讀
```

- 本 Repository `main` 分支是公開、跨 AI 共通治理的來源。
- 本機每 6 小時唯讀同步 `README.md`、`AGENTS.md` 與 `AI共同聊天規範.md` 到獨立鏡像；不得直接覆蓋本機完整規則、私人狀態或地方規則。
- 本機 MM 仍管理私人狀態、決策、專案、地方規則、本機路徑與檔案操作安全限制；這些內容不得放入公開 Repository。
- GitHub commit SHA、檔案 SHA-256 與回讀結果可驗證後，才可將該版本視為已同步。
- 公開共通治理與本機私人／地方規則跨界衝突時，停止衝突部分並請使用者確認；不得自行採用較寬鬆版本。

## 公開邊界

本 Repository 只發布去個人化的共通規範，不收錄：

- 個人目前狀態、卡點、提醒與私人決策
- 聊天逐字稿與未公開專案內容
- 本機絕對路徑
- 帳號、Token、Slack 識別資訊或其他敏感資料

- 維護方式：GitHub `main` 修改或合併、commit 回讀驗證、本機每 6 小時唯讀同步
